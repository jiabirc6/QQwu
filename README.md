# QQ屋 · 弹弹版

软体物理的水果合成小游戏：从一颗小葡萄开始，瞄准、投放，让相同的水果碰撞合成，一路合到大西瓜。使用原生 Canvas 实现，全部资源内嵌在一个 HTML 文件中，无需构建，可离线游玩。

## 在线游玩

- 自定义域名：https://qqw.190003.xyz/
- GitHub Pages：https://jiabirc6.github.io/QQwu/

下载 `index.html` 后用浏览器直接打开，即可离线游玩。

## 玩法

- 移动鼠标（或方向键）瞄准落点，点击或按 Enter 投放水果
- 相同的水果接触后会合成，从小葡萄到大西瓜层层升级
- 别让水果越过红线——堆得太高游戏就结束了

## 特色

- **软体物理**：水果碰撞会压缩、回弹、余晃，果肉 Q 弹
- **倾斜与软化**：按住「揉软一下」配合左倾/右倾调整堆叠，更好落位
- **果汁能量**：合成与落地积累能量，帮你刷新最高纪录
- **慢镜头实验室**：四分之一速度慢放，拖动时间轴逐帧回放单果落地、大小碰撞、同果合成
- **贴心细节**：新手教学、声音开关、暂停、减少动态效果、最高纪录本地保存

## 技术

- 原生 Canvas 2D，无第三方依赖
- 单文件 HTML，图片/样式/脚本全部内嵌
- GitHub Pages 托管（`main` 分支根目录），无构建步骤
